# Penalty Shootout

A small, browser-based penalty shootout game built with plain HTML, CSS, and JavaScript. The game runs locally and does not need an install, server, or internet connection.

## Play

1. Open `index.html` in a modern web browser.
2. Choose **Left**, **Center**, or **Right**.
3. Press **SHOOT!** before the 20-second timer runs out.
4. Continue after each shot. You and the AI take turns; the first to score 3 goals wins.
5. Use **Reset** to start over.

The **AI Auto-Play** checkbox controls whether the AI takes its turn automatically. When it is off, press **SHOOT!** to make the AI take its turn.

## Game features

- Three shooting directions and a goalkeeper that dives to try to save shots
- Score and round display
- 20-second turn timer
- Automatic AI opponent, with an option to disable its automatic turn
- Responsive layout for desktop and mobile screens

## Files

Keep the complete HTML document in a file named `index.html`. The styles and game logic are included in that file, so no separate assets or dependencies are required.

## Notes

The game is a lightweight demo: shot outcomes are randomized, and scores are not saved after the page is refreshed.
